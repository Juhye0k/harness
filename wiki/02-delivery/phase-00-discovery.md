# 0단계 — 문제와 비교 기준 확정

> 상태: 참고 제품 선정 완료 · 비교 실험 전 · 기준일: 2026-11-15 · 유지관리: 프로젝트 개발자

[위키 홈](../README.md) · [카테고리 목차](README.md)

## 목적

AlphaCut의 전체 기능을 복제하기보다 사용자가 필요한 핵심 흐름을 정의하고 같은 입력으로 비교할 기준을 만든다.

## 현재 결정

- 참고 제품: AlphaCut 사용 흐름.
- 핵심 범위: 후보 추천, 선택, 자막 수정, 출력.
- 첫 사용자 흐름 검증은 샘플 데이터로 진행.
- 도구의 내부 구현이나 점수 공식을 알고 있다는 가정은 하지 않음.

## 진행할 일

1. 사용할 권한이 있는 작은 영상을 확보하고 길이·언어·장르·음성 여부를 기록한다.
2. 우선 한 장르를 정하고, 별도로 전사 중심 영상과 시각적 사건 중심 영상을 구분한다.
3. 같은 영상·길이 조건에서 참고 제품의 구간·자막·사용자 수정 과정을 기록한다.
4. 사람이 사용 가능한 후보의 기준을 작성한다.

## 비교 기록 양식

| 항목 | 기록값 |
|---|---|
| 입력 | 데이터 ID, 파일 해시, 길이, 해상도, 음성 여부 |
| 설정 | 목표 클립 길이, 언어, 추가 요청, 실행일 |
| 결과 | 후보 구간, 제목·자막, 출력 길이 |
| 평가 | 문맥 완결성, 핵심 사건 포함, 자막 수정량, 작업 시간 |
| 제한 | 실패, 유료 기능 의존, 수동 조정 |

참고 제품의 점수를 정답으로 취급하지 않는다. 서로 다른 추천 결과가 모두 유용할 수 있다.

## 완료 기준

- 동일 입력·설정으로 반복할 수 있는 비교 절차가 있다.
- MVP에 포함·제외할 기능을 구분했다.
- 평가 데이터의 사용 범위와 보관 위치를 정했다.
