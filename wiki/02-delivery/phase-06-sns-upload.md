# 6단계 — 확인 후 SNS 업로드

> 상태: YouTube 우선 로컬 구현 · 실제 비공개 Shorts 업로드·분류 확인 · 기준일: 2026-11-16 · 유지관리: 프로젝트 개발자

[위키 홈](../README.md) · [단계 목차](README.md)

요청한 6단계는 성공한 영상 출력을 YouTube 계정에 연결하는 SNS-006 작업이다. 자막 편집이나 실제 추천 품질 평가의 완료를 전제하지 않고 기존 성공 출력에 연결한다. 다른 플랫폼·예약 게시·공개 운영은 범위에 포함하지 않는다.

완료 조건은 OAuth 연결, 계정·출력 버전·제목·공개 범위에 묶인 명시적 확인, 비공개 기본값, 중복 업로드 차단, 성공 여부가 불명확한 전송의 안전한 상태 조회, API·화면·제공자 대역 검증이다. 실제 계정 게시 완료는 별도 승인과 실제 검증 증거가 필요하다.

[설정·실행·제한](../05-development/youtube-upload.md), [요구사항·검사 연결과 작업 기록](../05-development/harness/changes/sns-006-upload.md)을 기준으로 한다. 일반 CI에서는 실제 Google 계정·자격 증명·유료 AI를 사용하지 않는다.
