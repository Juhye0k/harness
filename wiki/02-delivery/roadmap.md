## 단계 운영 원칙

VIDEO-005는 [Groq 무료 연동](../05-development/groq-free-ai.md)과 품질 평가 준비를 진행했다. 로컬 자동 검증은 완료했으며 다음 단계는 Free 계정 키 설정과 승인된 한국어 샘플의 실제 평가다.

전사와 추천은 독립 설정이며 현재 기본은 Groq 전사·추천 비활성이다. 먼저 대사와 시간 정보만 평가하고, 이후 저장된 전사를 추천 실험에 재사용한다.

일정은 주 단위 약속보다 **진입 조건과 완료 증거**로 관리한다. 단계 문서를 작성했다고 구현이 끝난 것은 아니다. VIDEO-004는 전사 기반 추천·선택 추출을 구현한다. SNS-006은 성공 출력의 YouTube 업로드를 추가하며 실제 게시 미검증이다. 실제 모델 품질 평가와 자막 편집은 후속 작업이다.

## 의존 관계

`0 → 1 → 2 → 3 → 4 → 5`

요청된 6단계는 기존 성공 출력을 사용한다. 5단계의 모든 공개 준비나 자막 편집이 완료됐다는 의미는 아니다.

영상 기초 학습은 2단계에서 실제 추출 실험과 함께 수행한다. 3단계는 실제 AI 없이도 사용자 흐름을 검증한다. 4단계에서 같은 데이터 형식으로 샘플 분석기를 실제 분석기로 교체한다.

현재 개발 환경을 이미 만들었으므로, 시작 시점의 학습 순서와 완전히 같을 필요는 없다. 다음 기능 개발은 2단계의 작은 입력·출력 계약부터 진행한다.

## 단계 종료 기록

각 단계 완료 시 다음을 [현황 기록](../07-governance/status.md)에 남긴다.

- 검증한 커밋과 실행 명령
- 입력 데이터의 식별자와 설정 버전
- 통과·실패 결과와 재현 방법
- 남은 제한, 다음 단계의 선행 조건

측정 없는 완료 선언, 미실행 검사의 통과 처리, 샘플 응답을 실제 AI 결과로 소개하는 것을 금지한다.

표시 자막 분할·원본 영상 기준 SRT는 VIDEO-005 후속 로컬 구현이다. [제품 초안과 계약](../05-development/subtitle-segmentation.md)을 따르며 내용 편집·자막 합성·실제 가독성 평가는 후속이다.
