## 단계 운영 원칙

미반영 작업의 main 통합은 [INTEGRATE-001](../05-development/harness/records/2026-11-17-main-integration.md)을 따른다. 편집·최종 출력·로컬 업로드와 분석 접수 복원·실패 검사는 로컬 구현됐으며, 아래 이전 단계의 후속 표기는 해당 시점의 이력이다. 실제 모델 품질·최대 업로드 부하·운영 배포는 별도 작업이다.

FLOW-001은 개별 품질 개선에 앞서 [시작부터 끝까지의 한 흐름](../05-development/complete-flow.md)을 로컬 연결했다. 추천 후보의 자막 편집·불변 저장·실제 렌더링·다운로드와 확인 후 SNS 전송을 브라우저로 검사한다. 모델·SNS 대역의 흐름 통과와 실제 제품 품질을 구분하며, 이후 실제 입력의 품질·실계정·부하 검사에서 발견한 실패를 회귀 검사와 규칙에 반영한다. 아래의 편집·합성이 후속이라는 문구는 이전 단계의 기록이다.

추천 개선은 [RECO-EVAL-001](../05-development/recommendation-improvement-loop.md)에 따라 수작업 평가·수정·재검증 1~3회로 절차를 확인한 뒤 반복 하네스로 옮긴다. 실제 추천 품질 평가와 자율 AI 작업자 연결은 도구 구현과 구분한다.

VIDEO-005는 [Groq 무료 연동](../05-development/groq-free-ai.md)과 승인된 한국어 샘플의 전사 생성을 진행했다. TR-EVAL-002의 [정답 입력·품질 평가](../05-development/transcript-quality-evaluation.md)와 SUB-ALIGN-003의 [구간별 단어 복구](../05-development/word-alignment-recovery.md)를 통합했다. 고정 샘플의 원문·시간 범위 보존은 통과했으나 표시 가독성 초안은 미달이다. 다음은 남은 긴 자막·짧은 표시 개선과 원음을 확인한 정답 전사에 근거한 인식 정확도 평가다. 코드 검사 통과를 실제 품질 통과로 해석하지 않는다.

전사와 추천은 독립 설정이며 현재 기본은 Groq 전사·추천 비활성이다. 먼저 대사와 시간 정보만 평가하고, 이후 저장된 전사를 추천 실험에 재사용한다.

일정은 주 단위 약속보다 **진입 조건과 완료 증거**로 관리한다. 단계 문서를 작성했다고 구현이 끝난 것은 아니다. VIDEO-004는 전사 기반 추천·선택 추출을 구현한다. SNS-006은 성공 출력의 YouTube 업로드를 추가하며 실제 비공개 Shorts 업로드·분류 확인이다. 실제 모델 품질 평가와 자막 편집은 후속 작업이다.

## 의존 관계

`0 → 1 → 2 → 3 → 4 → 5`

요청된 6단계는 기존 성공 출력을 사용한다. 5단계의 모든 공개 준비나 자막 편집이 완료됐다는 의미는 아니다.

영상 기초 학습은 2단계에서 실제 추출 실험과 함께 수행한다. 3단계는 실제 AI 없이도 사용자 흐름을 검증한다. 4단계에서 같은 데이터 형식으로 샘플 분석기를 실제 분석기로 교체한다.

현재 개발 환경을 이미 만들었으므로, 시작 시점의 학습 순서와 완전히 같을 필요는 없다. 다음 기능 개발은 2단계의 작은 입력·출력 계약부터 진행한다.

## 단계 종료 기록

각 단계 완료 시 다음을 [현황 기록](../07-governance/status.md)에 남긴다.

- 검증한 커밋과 실행 명령
- 입력 데이터의 식별자와 설정 버전
- 통과·실패 결과와 재현 방법
- 남은 제한, 다음 단계의 선행 조건

측정 없는 완료 선언, 미실행 검사의 통과 처리, 샘플 응답을 실제 AI 결과로 소개하는 것을 금지한다.

표시 자막 분할·원본 영상 기준 SRT는 VIDEO-005 후속 로컬 구현이다. [제품 초안과 계약](../05-development/subtitle-segmentation.md)을 따르며 내용 편집·자막 합성·실제 가독성 평가는 후속이다.

자막 편집·최종 출력의 첫 단계로 [한국어 자막 포함 세로 영상 샘플](../05-development/portrait-subtitle-sample.md)을 로컬 CLI로 추가한다. 합성 입력의 시간 변환·폰트·여백·출력 검사를 확인하는 범위이며 편집 저장·UI·비동기 업무 출력·실제 발화 정렬은 후속이다. 실행 근거는 해당 작업 기록을 따른다.
