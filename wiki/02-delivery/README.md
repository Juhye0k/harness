# 단계별 실행 계획

> 단계별 실행 계획에 속한 문서를 찾는 목차입니다. 아래 글의 설명을 읽고 필요한 주제로 이동하세요.

[위키 홈](../README.md)


각 단계의 설계·산출물·완료 기준을 확인한다.

- [단계별 실행 계획](roadmap.md) — 개발 단계는 일정 약속보다 진입 조건과 검증 증거로 관리합니다
- [0단계 — 문제와 비교 기준 확정](phase-00-discovery.md) — 추천 결과를 비교하려면 먼저 같은 영상과 평가 기준이 필요합니다
- [1단계 — 프로젝트 구조와 최소 하네스](phase-01-foundation.md) — 기능을 만들기 전에 실행 환경과 검사 방법부터 맞췄습니다
- [2단계 — 영상 기초와 결정적 작업 처리](phase-02-video-jobs.md) — AI가 고른 구간도 영상으로 정확하게 잘라낼 수 있어야 쓸모가 있습니다
- [3단계 — 샘플 기반 웹 MVP](phase-03-web-mvp.md) — 서버 기능이 있어도 사용자가 결과까지 도달하지 못하면 제품 흐름은 완성되지 않습니다
- [4단계 — 실제 분석과 품질 평가](phase-04-ai-evaluation.md) — 추천을 생성하는 것과 쓸 만한 추천을 만드는 것은 별도의 검증이 필요합니다
- [5단계 — 새 기능과 공개 준비](phase-05-extension.md) — 공개 서비스로 운영하려면 새 기능뿐 아니라 비용·권한·장애 대응을 준비해야 합니다
- [6단계 — 확인 후 SNS 업로드](phase-06-sns-upload.md) — 완성된 영상을 외부에 올리는 행동에는 별도의 확인이 필요합니다
