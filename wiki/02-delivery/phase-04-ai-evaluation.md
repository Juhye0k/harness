# 4단계 — 실제 분석과 품질 평가

> 상태: 실험 설계 초안 · 미구현 · 기준일: 2026-11-15 · 유지관리: 프로젝트 개발자

[위키 홈](../README.md) · [카테고리 목차](README.md)

## 목적

샘플 후보를 실제 분석기로 교체하고 음성·영상·텍스트의 결합이 단일 신호보다 유용한지 검증한다. Python 선택의 핵심 활용 단계다.

## 파이프라인 설계

`원본 → 음성·프레임·전사문 → 후보 구간 → 신호별 특징 → 점수 결합 → 중복 정리 → 추천`

| 신호 | 첫 실험 후보 | 주의점 |
|---|---|---|
| 음성 | 음량 변화·무음·발화 속도 | 큰 소리가 항상 중요 장면은 아님 |
| 영상 | 움직임·장면 전환·프레임 품질 | 컷이 많은 광고가 높은 점수를 받을 수 있음 |
| 텍스트 | 핵심 사건·문맥 완결성·도입부 | 전사 오류와 영상에만 있는 사건 누락 |

특징 값을 비교 가능한 범위로 정규화하고 가중치를 버전별 설정으로 분리한다. 예시 가중치를 검증된 공식으로 고정하지 않는다. 축구와 인터뷰는 평가 집단을 나눠 비교한다.

## 저장할 실험 정보

입력 ID·해시, 분석기 버전, 모델·프롬프트 버전, 후보 경계, 신호별 특징·점수, 가중치, 실행 시간, 호출량·비용, 최종 순위를 기록한다. 사용자가 고친 자막은 원본 전사와 함께 구분해 보관한다.

## 평가 절차

1. 개발용 영상과 최종 비교용 영상을 분리한다. 최종 평가 영상을 보며 가중치를 반복 조정하지 않는다.
2. 사람이 유용한 구간과 판단 이유를 표시한다. 평가자가 한 명이면 그 한계를 명시한다.
3. 텍스트만 사용하는 기준 방식과 신호를 결합한 방식을 같은 조건에서 비교한다.
4. 한 신호씩 제외해 어떤 신호가 개선에 기여했는지 확인한다.
5. 가능하면 참고 제품에도 같은 입력·길이 조건을 적용해 결과와 수정 시간을 비교한다.

| 평가 | 정의 |
|---|---|
| 상위 K개 유용성 | 상위 K개 중 사용 가능 판정을 받은 비율 |
| 구간 일치 | 사람이 표시한 구간과 시간 교집합/합집합 비율, 단 유일한 정답으로 취급하지 않음 |
| 문맥 완결성 | 시작과 끝이 사건·발화를 이해하는 데 필요한 내용을 포함하는지 |
| 후보 다양성 | 비슷한 구간이 반복 추천되는 정도 |
| 자막 품질 | 같은 정규화 규칙의 글자 오류율과 실제 수정 시간 |
| 효율 | 입력 1분당 비용, 대기 시간과 처리 시간 각각 |

K, 표본 수, 합격 기준은 기준 실험 이후 기록한다. 아직 수치 목표나 달성 결과는 없다.

## 하네스 개선과 완료 기준

일반 CI는 고정 AI 응답으로 형식·범위·실패 처리를 검사한다. 실제 모델 평가는 비용 제한을 둔 별도 실행으로 구성한다. 발견한 구간 초과·자막 누락·중복 후보 사례는 작은 회귀 데이터로 추가한다.

완료 시 기준 방식 대비 결과표, 실패 사례, 비용, 설정 버전, 재실행 절차를 제출한다. 영상 품질을 AI 리뷰 한 번이나 문법 검사 통과로 대체하지 않는다.
