# 구현 현황과 검증 기록

> 현재 사용할 수 있는 기능과 검증이 남은 범위를 확인하는 문서입니다. 최신 main의 통합 근거를 먼저 보고, 기능별 과거 검사 결과는 당시 기록으로 구분해 읽을 수 있습니다.

**입력부터 추천·자막 편집·세로 출력·다운로드·YouTube 게시까지 구현했다.** 실제 검수본 한 건의 다운로드와 비공개 Shorts 게시를 확인했다. 같은 원본의 재추천은 후보 1개였고, 게시 제목은 사전 승인안과 달랐다.

**11월 20일 실제 영상 재검증.** 사용자가 검수한 같은 편집본으로 원본 자막이 보이는 두 구간을 지정해 다시 출력했다. MP4 969프레임에서 지정 구간의 편집 자막만 숨겨졌고, SRT에는 검수 자막 34개의 문구와 시간이 그대로 남았다. [검증 방법과 한계](../05-development/harness/records/2026-11-18-final-output-e2e.md).

같은 날 개발 제작실의 API·영상 워커·분석 워커를 `main` `b09265e`로 맞추고 DB·저장 영상·작업을 보존했다. 저장 전사 147구간으로 실제 Groq 후보 제안과 채점이 성공했다. API와 브라우저는 동일한 후보 1개와 52.5점을 표시했다. 기존 기록으로는 모델 제안 건수와 후속 선정에서 제외된 건수를 구분할 수 없었다.

보정 MP4는 파일이 같은지 해시로 대조한 뒤 별도의 로컬 SNS 환경에서 한 번 비공개로 게시했다. YouTube API에서 처리 완료를 확인했고 사용자가 Studio Shorts 목록에서 동일 영상 ID를 확인했다. 실제 제목은 사전 승인안과 달랐다. [게시 검증 기록](../05-development/harness/records/2026-11-18-sns-final-output-validation.md).


## 기능별 현재 상태

| 기능 | 구현·확인한 것 | 아직 확인할 것 |
|---|---|---|
| 영상 입력 | 링크와 로컬 파일, 크기·형식·원본 검증 | 최대 크기의 실제 부하 |
| AI 분석 | 한국어 전사·후보 추천·서버 점수. 이전 실제 실행에서 후보 2개, 이번 재추천에서는 1개 | 단계별 후보 수 기록, 복수 후보 재현, 사람의 추천 적합성 평가와 정답 전사 대비 정확도 |
| 자막 편집 | 원본 전사와 분리, 문구·시간 수정, 실제 후보 한 건의 34개 자막을 사용자가 원음 검수하고 저장 | 다양한 입력에서 발화 일치와 빠른 자막 가독성 |
| 최종 출력 | 실제 검수본의 720×1280 MP4·SRT, 음성 포함 전체 디코딩과 다운로드 바이트 일치 확인 | 다른 입력의 화면 구성과 자막 동시 표시 범위 |
| YouTube | 실제 편집본 비공개 게시 1건, 원격 처리 완료, Studio Shorts 분류 확인 | 사전 승인 제목과 게시 직전 제목의 일치 확인 |
| 하네스 | 기본·통합·실패·실제 프로세스 종료 검사 | 장기 운영·실부하·다양한 실제 입력 |
| 운영 | 개발용 Compose·권한·자료 만료/정리 기반 | 운영 배포·HTTPS·백업·모니터링 |
