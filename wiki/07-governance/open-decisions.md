# 미결정 사항과 결정 시점

## 관리 방식

항목을 구현 전에 닫는다. 담당은 현재 프로젝트 개발자이며, 마감일을 임의로 정하지 않고 영향을 받는 단계의 진입 조건으로 관리한다. 아래 항목은 기능 구현 티켓이 아니라 결정이 필요한 질문이다.

| ID | 미결정 질문 | 선택 기준 | 결정 시점 |
|---|---|---|---|
| D-01 | 첫 평가 장르·사용 가능한 영상은? | 사용 권한·음성/시각 신호·반복 가능성 | 0단계 비교 실험 전 |
| D-02 | 초기 CLI 기준 확정 | 20분·500MiB·10초 ±0.1초; [계약](../05-development/video-extraction.md) | 웹 연결 시 재검토 |
| D-03 | 객체 저장소·보관 기간·리전은? | 가격·전송·삭제·파일 접근 요구 | 3단계 업로드 연결 전 |
| D-04 | 초기 정책 확정: 조건부 선점·수동 중단 처리·자동 복구 없음 | [ADR-003](../04-decisions/adr-003-redis-celery.md) | 자동 복구·외부 공개 전 재검토 |
| D-05 | 첫 음성 인식·텍스트·영상 모델은? | 한국어·타임스탬프·품질·비용·처리량 | 4단계 실제 분석 전 |
| D-06 | 점수 정규화·가중치·K·품질 기준은? | 기준 실험·장르 차이·실패 사례 | 4단계 평가 전 |
| D-07 | 초기 CLI 출처 확정 | 공개 YouTube 단일 영상·MP4 직접 링크; 로그인·라이브 제외 | 출처 확대 시 재검토 |
| D-08 | 인증과 사용자 데이터 삭제 정책은? | 소유권·보존·공개 서비스 범위 | 외부 사용자 테스트 전 |
| D-09 | 월 예산·사용량 한도·배포 공급자는? | 영상 1분당 비용·예상 작업량 | 공개 배포 전 |
| D-10 | 새 기능과 SNS 지원 범위는? | 사용자 실패 사례·개선 효과·연동 비용 | 5단계 착수 전 |

## 결정 기록 형식

결정일, 관련 ID, 선택, 대안, 판단 근거, 영향 문서, 검증 방법을 남긴다. 아키텍처 경계를 바꾸면 [ADR](../04-decisions/README.md)을 추가한다. 채택 전 제안은 '검토 중'으로 표시하고 기존 결정을 조용히 덮어쓰지 않는다.
