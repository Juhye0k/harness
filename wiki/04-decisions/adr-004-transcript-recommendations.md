# ADR-004 — 전사 기반 추천과 제공자 분리

> 상태: 채택 · 기준일: 2026-11-15

[위키 홈](../README.md) · [의사결정 목차](README.md)

## 문제와 결정

여러 장르를 다루되 첫 구현은 한국어 대화·인터뷰의 음성과 텍스트로 검증한다. 시각 정보를 보지 않은 모델이 스포츠 득점이나 게임 이벤트를 확인한 것처럼 설명하지 않도록 분석 근거를 화면에 표시한다.

시간 정보가 있는 한국어 전사는 Azure Speech Fast Transcription, 후보 제안·평가는 OpenAI Responses 구조화 출력으로 분리한다. 모델 기본값은 gpt-5.6-terra이며 환경 설정으로 교체할 수 있다. 실제 제공 모델 이름은 응답에서 관측된 값과 설정값을 구분해 기록한다. 선택은 실제 한국어 정확도 평가를 완료했다는 뜻이 아니다.

서버가 전사 ID로 구간을 계산하고 가중치·중복 제거를 수행한다. 모델은 정해진 JSON 데이터만 반환하며 파일 경로·도구·게시 권한을 갖지 않는다. 전사문 안의 지시는 사용자 명령이 아닌 데이터로 처리한다. 제안과 평가를 분리하면 비용이 증가하지만 후보 선정과 순위 기준을 따로 검사할 수 있다. 두 호출이 같은 모델이므로 평가 독립성이나 품질을 보장하지는 않는다.

## 대안과 절충

| 대안 | 장점 | 이번에 선택하지 않은 이유 |
|---|---|---|
| 로컬 ASR 모델 | 외부 전송 감소, 사용량 비용 감소 가능 | 1인 운영에서 모델·메모리·추론 성능 관리가 추가됨 |
| 영상 전체 멀티모달 분석 | 영상 사건·장면을 직접 활용 | 비용·샘플링·시간 정합성 평가 범위가 커짐 |
| 제안과 점수를 한 호출로 생성 | 호출 수 감소 | 제안 유효성 검사 후 별도 평가하는 경계를 잃음 |
| 장르별 가중치 선적용 | 맞춤화 가능 | 아직 장르별 비교 표본·근거가 없음 |
| 모든 후보 사전 렌더링 | 즉시 미리보기 | 사용하지 않을 후보의 CPU·저장 비용 발생 |

원본·전사는 asset ID로 재사용하고 선택한 후보만 인코딩한다. 캐시 버전이 같아야 전사를 재사용하며 URL 문자열이 같다는 이유로 원본 동일성을 가정하지 않는다. 분석 큐를 분리해 긴 모델 호출이 기존 10초 추출 작업을 막는 영향을 줄인다. 자동 복구·재시도는 불확실한 유료 호출을 중복 실행할 수 있어 이번 범위에서 제외한다.

## 재검토 조건

장르별 고정 평가 표본과 사람의 선호 데이터가 확보되면 음성 특징·프레임·이벤트 신호를 원본 시간축에 맞춰 추가한다. 먼저 텍스트 기준 방식과 비교하고 개선이 확인된 신호만 사용한다. 처리량·비용이 병목일 때 로컬 ASR, 작업 분할, 저장소 이동을 검토하며 지금은 별도 마이크로서비스를 만들지 않는다.
