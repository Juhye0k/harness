## 제품 구현과의 경계

`app/`의 다운로드·추출·길이 검사·프로세스 제한은 제품 구현이다. `tests/`는 그 동작을 판정하고, 공통 검사 명령과 CI가 실행한다. 개발용 Compose는 인프라 재현에 사용하지만 코딩 에이전트 권한을 제한하는 장치는 아니다. 파일·명령·네트워크 권한은 에이전트 실행 환경에서 별도로 설정한다.

제품의 `result.json`은 영상 처리 결과이며 개발 이력이 아니다. 개발 기록은 작업 ID에 연결한 프롬프트·결과 기록·개선 문서·Issue·PR에 남긴다. 공개 가능한 프롬프트 발췌와 결과 요약만 기록하며 원본 대화 전체·민감한 로그는 공개 문서에 넣지 않는다.

## 현재 제공하는 것과 한계

지침, 의존성 잠금, 자동 검사, CI 설정, 리뷰 기준과 수동 개선 기록을 제공한다. 프롬프트·결과는 작업을 수행하는 에이전트가 문서로 작성·갱신한다. 자동 대화 수집·프롬프트 성과 집계·자동 AI 코드 리뷰·자동 수정 에이전트는 아직 없다. CI 파일이 존재해도 GitHub 병합 보호가 설정되었다는 뜻은 아니다.

공식 열람 위치는 GitHub Wiki이며 이 폴더는 게시 원본이다. 이번 구조 정리는 로컬 변경이며, 원격 게시 완료와 구분한다. 이전 문서 경로는 안내 페이지로 유지한다.
