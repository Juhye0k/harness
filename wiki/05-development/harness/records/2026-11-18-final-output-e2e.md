# 원음 확인부터 최종 다운로드까지 — FLOW-E2E-003

> 고정 초안의 34개 자막에서 82어절 보존과 동일 기준의 전체·구간별 7/208 글자 오류를 재확인했다. 합성 회귀 검사는 미검수 저장과 새로고침 후 출력 차단, 확정본과 실제 다운로드 파일의 일치를 확인한다. 실제 출력은 검증용 코드 반영과 사용자 원음 확인을 기다린다.

[작업 기록 목차](README.md) · [기존 전체 흐름](../../complete-flow.md)

## 요청과 완료 기준

- P1 요약. 별도 작업 트리에서 합성 회귀 검사를 준비하고, 통합 코드가 실행되면 고정 영상의 34개 자막을 편집기에서 대조한다.
- 사용자 원음 확인 전 출력 요청은 거절되어야 한다. 실제 확인이 저장된 불변 버전에서 영상과 자막을 내려받아 내용·시간·파일 일치를 검증한다.
- 시작 커밋은 `12673d88f8b1fa5a5cc5cd808781d3afd305e0d4`다. 전용 브랜치는 변경 없이 시작했다.
- 실행 정보는 Windows, PowerShell, uv, FFmpeg 및 Playwright다. 에이전트 모델·사용량·비용은 알 수 없음이다.

## 검증과 남은 조건

| 검사 | 관측 결과 |
|---|---|
| 기본 검사 | Windows에서 `uv run --no-sync python scripts/verify.py` 실행. Ruff, 기본 405개, Alembic SQL 통과. 기존 잠금 환경과 로컬 FFmpeg 사용. |
| 격리 통합 검사 | 전용 Compose의 PostgreSQL·Redis·Celery·FFmpeg·Chromium에서 전체 흐름과 버전 API 3개 통과. `portrait-edited-v1` 기준 브랜치에서 실행했다. |
| 고정 자료 읽기 검증 | 원본과 고정 기준 해시가 일치했다. 같은 18구간·208글자로 비교했으며, 34개 초안은 82어절을 순서대로 보존하고 표시 규칙을 통과했다. |
| 기존 실행 환경 조회 | 후보 시간과 전사 버전, 원본 영상의 부분 응답을 확인했다. 최신 저장본은 과거 29개 버전이다. |
| 실제 최종 출력 | 통합 코드가 실행되고 그 편집 버전의 사용자 확인이 기록되면 파일, 재생, 화면 품질을 검증한다. |

`portrait-edited-v2` 실행과 전체 필수 CI는 통합 브랜치에서 확인한다.

11월 19일 재개 시 고정 원본과 34개 미확정 초안의 해시, 82어절, 전체·구간별 7/208을 다시 확인했다. 호스트에서 8003 준비 상태를 조회하지 못해 새 버전 저장과 실제 출력 증거는 대기 중이다.

[합성 전체 흐름 검사](../../../../tests/integration/test_complete_flow.py)는 원본 0초 이후의 후보를 사용해 SRT의 각 번호·시각·한글 줄바꿈과 브라우저 다운로드 바이트를 대조한다. MP4 해시는 브라우저 다운로드와 SNS 시험 대역을 비교한다. [버전 API 검사](../../../../tests/integration/test_caption_versions.py)는 미검수 오류 코드와 출력 작업 미생성, 다른 후보의 출력 접수 거부를 확인한다.

## 사람의 판단과 남은 작업

사용자가 지정한 전용 트리에서 자동 검사와 읽기 검증을 수행했다. 원음 확인은 사용자에게 남아 있다. 초안의 끝은 다음 단어 시작을 사용하는 표시 시각이다. 잘린 두 경계에서 실제 발화 끝은 확인되지 않았다.

제품 외부 AI 호출·실계정 게시 없음. 제품 코드 통합 및 GitHub Wiki 게시는 FLOW-CAPTION-003 담당이 조정한다.

## 포트폴리오 요약

사용자 확인을 전제로 하는 작업을 합성 데이터에서 재현했다. 미검수본·확정본·작업·다운로드의 연결을 검증하고, 실제 영상의 기준 자료와 사용자의 원음 판단을 독립적으로 추적한다.
