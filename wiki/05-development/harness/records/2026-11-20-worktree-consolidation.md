# 워크트리 변경 통합

> 여러 작업 폴더에 남아 있던 변경을 최신 `main`과 대조해 통합한다. 재현 가능한 검사를 통과하고 원격 반영을 확인한 뒤, 안전하게 제거할 수 있는 체크아웃을 정리한다.

[작업 기록 목차](README.md) · [쇼츠 제작 화면](2026-11-20-project-workspace.md)

## 요청과 기준

사용자는 워크트리에 흩어진 변경을 `main`에 반영하고 작업 폴더를 정리해 달라고 요청했다. 시작 기준은 PR #18의 `8af539d`다. 기존 변경이 있는 원본 워크트리는 그대로 두고 별도 체크아웃에서 합친다. 원격에 이미 반영된 변경은 다시 적용하지 않고 오래된 스냅샷과 아직 유효한 작업을 비교한다.

## 반영한 변경

- 편집기에서 원본 화면에 이미 자막이 있는 구간을 지정할 수 있게 했다. 새 자막은 해당 영상 구간에서만 숨기고 전체 SRT는 기존 검수본을 따른다. SNS 화면에서 편집기로 돌아올 때 출력 작업을 가리키는 주소도 유지한다.
- Groq 실패 응답의 본문은 명시적으로 켠 경우에만 분석 워커 전용 볼륨에 남긴다. 공개 응답과 작업 문서에는 원문을 포함하지 않는다.
- 전사·자막 분할과 단어 정렬·전사 평가의 이전 실험은 `94f2474` 이후 제품과 검사에서 이어지는 것을 확인했다. 개발 환경 복구의 최신 결과는 원격 `main`의 기존 기록을 따른다. 이전 체크아웃의 커밋과 로컬 차이는 비공개 복구본으로 보관했다.

## 검증

Windows의 통합 체크아웃에서 저장 공간을 정리하고 기존 FFmpeg 실행 파일의 정확한 위치로 검사 환경을 구성했다. Ruff, 기본 검사 425개, Alembic 오프라인 SQL을 통과했다. Wiki 빌드는 102페이지와 내부 링크 743개를 확인했다. 실제 Groq 재호출과 SNS 게시는 이번 통합 검증 범위에 포함하지 않았다.
