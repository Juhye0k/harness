# 화면 정렬 자막을 웹 편집기에 연결 — FLOW-CAPTION-003

> 원본과 일치하는 화면 관측이 있으면 분석 워커가 저장 전사의 단어 시각을 따라 편집 초안을 만든다. 고정 영상의 34개 초안을 같은 기준선에서 재현했고 웹 편집기에 별도 미확정 버전으로 적용할 수 있도록 했다.

## 요청과 완료 기준

사용자 요청 요약. 고정 영상의 34개 자막을 재현하고 최신 편집을 확인한 뒤 새 미확정 버전으로 저장한다. 새 분석에도 자료가 갖춰지면 기존 비동기 워커에서 정렬을 적용한다. 원음 확인은 사람이 판단한다. 3·4번의 독립 변경을 결합하고 필수 검사를 통과한 커밋을 병합한 뒤 실행 담당과 검증 담당에 인수한다.

전용 작업 트리는 `12673d88f8b1fa5a5cc5cd808781d3afd305e0d4`에서 깨끗하게 시작했다. 기존 루트에는 별도 작업의 미커밋 변경이 관측됐다. 개발 에이전트 모델 사용량과 비용은 알 수 없다.

## 구현과 검증

- 준비된 원본 관측을 사용하는 정렬은 기존 분석 워커에서 실행한다. 원본과 맞지 않거나 읽기 조건을 만족하는 분할이 없으면 기존 전사 초안을 사용한다. [준비·실행 조건](../../source-caption-evaluation.md).
- 편집 화면은 기존 저장본을 유지하고 직전 버전과 비교할 수 있게 한다. 저장 시 서버가 조회 당시의 최신 버전 ID를 비교한다. 동시 저장 충돌을 알리고, 응답이 끊겼을 때 같은 내용을 다시 요청해도 불변 버전은 한 개다.
- 고정 영상 CLI 실행은 기존 기준선 208자를 사용했다. 새 초안의 전체·구간별 차이는 각각 7/208이고 표시 제약 위반은 0건이었다. 재현한 34개 단위가 미확정 초안 JSON과 일치했다. 원본 영상의 해시와 후보 범위·전사 버전을 기존 런타임에서 읽어 대조했다.
- 작업 중 기본 검사에서 411개를 통과했다. 새 자동 정렬·저장 충돌·브라우저 회귀 검사를 추가했고 결합 검사 결과는 통합 기록에 연결한다.

## 사용자 판단과 남은 확인

사용자는 실제 원음 확인과 SNS 게시 여부를 결정한다. 두 경계 단어의 실제 발화 끝과 새 초안의 원음 일치는 확인 대기다. 실제 출력·SNS 전송과 추가 모델 호출을 실행하지 않았다.

코드·문서·재현 가능한 검사를 작업 트리에 남겼다. GitHub Wiki 게시 결과는 완료 보고에서 확인할 수 있다.
