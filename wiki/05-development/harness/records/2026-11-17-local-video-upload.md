## 검사·실패·수정

- 크기·해시 불일치·20분 초과 원본 미공개와 경로 검증 단위 4개 통과.
- 업로드 전용 실제 PostgreSQL·Celery·Chromium·FFmpeg 통합 8개 통과. 파일 선택·전송·검증·새로고침 무재전송·10초 출력·전사 재사용과 인증 모드의 큰 본문·크기 제한·중복·타인 접근을 확인했다.
- 최초 기본 검사는 pytest 공용 임시 폴더 권한 오류로 setup 130개가 중단됐다. 전용 basetemp로 접근을 바꿨다. 다른 진행 작업의 서식 오류가 있던 시점에는 전체 pytest를 별도로 실행해 369개 통과를 확인했고 이후 Ruff·서식도 통과했다.
- 첫 전체 통합은 91개 통과·2개 실패였다. FastAPI Depends가 생성 시 함수를 고정하므로 모듈 함수 monkeypatch만으로는 발행 대역이 적용되지 않아 실제 worker와 경쟁했다. dependency_overrides로 수정했다. 별도 추천 평가 브라우저 검사의 AGENTS.md 누락은 테스트 이미지 COPY와 읽기 전용 마운트로 보완했다. 업무 assertion을 약화하지 않았다.
- 수정 후 실행하려던 검사는 사용자 중단으로 종료 여부가 불명확했다. 재개 시 프로세스 부재·로그 미생성을 확인해 별도 프로젝트에서 다시 검증한다. 최종 결과는 아래에 갱신한다.
