# 웹에서 영상 추출 — VIDEO-003

> 브라우저에서 영상 추출을 접수하고 상태·미리보기·다운로드를 확인합니다. 새로고침 복원과 중복 제출 방지, 통신 오류와 처리 실패를 구분하는 동작을 설명합니다.

[위키 홈](../README.md) · [개발 목차](README.md)


## 사용자 흐름

`docker compose up --build -d` 후 `http://localhost:8000/extract`에 접속한다. 공개 영상 링크와 시작 시간(초)을 입력하면 10초 추출을 접수한다. 대기·실행·완료·실패 상태를 표시하고, 완료 후 영상 미리보기와 MP4 다운로드를 제공한다.

접수 후 주소는 `/extract?job=<UUID>`다. 기존 `/?job=<UUID>` 주소도 같은 화면을 연다. 주소를 저장하거나 새로고침하면 기존 작업을 조회한다. 다른 영상을 처리하려면 ‘새 영상 추출하기’를 누른다.

## 구현 선택

FastAPI가 `app/static/`의 HTML·CSS·JavaScript를 같은 주소에서 제공한다. 프런트엔드 서버·Node 빌드·CORS 설정을 추가하지 않았다. 현재 입력·상태·다운로드 한 흐름에는 충분하며, 복잡한 자막 편집 요구가 확정되면 UI 구조를 다시 검토한다. Playwright는 테스트용 Python 개발 의존성이며 일반 실행 이미지에는 브라우저나 tests를 넣지 않는다.

## 실패·동시성 계약

- 요청 중 버튼을 비활성화하고 이벤트 처리에서도 중복 제출을 막는다. 서로 다른 탭·새 요청의 서버 중복 방지는 별도 요구사항이다.
- 작업 접수 응답이 불확실하면 자동 재전송하지 않는다. 이미 등록됐을 가능성을 알린다.
- 503 응답에 유효한 작업 ID가 있으면 해당 작업을 조회한다. 사용자가 반복 요청하도록 유도하지 않는다.
- 작업 상태는 2초 간격으로 순차 조회하며, HTTP 요청은 15초 제한을 둔다. 조회 실패 시 마지막 작업 상태를 유지하고 '상태 다시 조회'를 제공한다.
- 조회 실패를 작업 failed로 바꾸지 않는다. 서버가 실패로 보고한 경우에만 처리 실패를 표시한다.
- 새 주소로 이동한 뒤 늦게 도착한 응답은 세대 번호로 무시한다. 성공·실패·404에서는 자동 조회를 멈춘다.
- 파일 410·미리보기 실패는 결과 접근 오류로 표시하며 기존 완료 상태를 처리 실패로 바꾸지 않는다.
- 서버 문자열은 textContent로 렌더링하고 미리보기·다운로드 주소는 현재 작업 ID로 구성한다.

## 하네스와 완료 기준

| 요구사항 | 검사 |
|---|---|
| 인프라 없이 웹 자산 제공, GET에서 작업 생성 없음 | unit/test_web.py |
| 실제 요청→추출→미리보기→다운로드 | integration/test_web_browser.py, 실제 API·DB·Redis·워커·FFmpeg |
| 새로고침 시 POST 추가 없음 | 실제 브라우저 요청 횟수 검사 |
| 상태별 표현, 조회 실패 후 재조회 | 브라우저 API 응답 대역 |
| 중복 제출·입력 오류·불확실한 접수 | 브라우저 요청 보류·오류 대역 |
| 잘못된 ID·없는 작업·없는 결과 파일 | 브라우저 404/410 검사 |
| HTML 형태 오류 메시지 실행 금지 | 브라우저 DOM 검사 |
| 모바일 화면 가로 넘침 없음 | Chromium 390px 화면 검사 |

기존 `compose.integration.yaml`의 runner가 브라우저 검사도 실행한다. 별도 마커 우회 없이 필수 `integration` CI에 포함하며 실패하면 main 병합을 차단한다. Chromium 설치 실패도 검사 실패로 취급한다. 실행 명령은 [검증 안내](harness/verification.md)를 따른다.

## 검증 기록

기본 검사 86개와 브라우저 14개를 포함한 실제 통합 검사 27개가 통과했다. Chromium에서 합성 영상의 10초 미리보기와 실제 MP4 다운로드, 새로고침 후 POST 1회 유지, 모바일 390px 화면을 확인했다. 테스트 이미지에서 Node 드라이버의 libatomic 누락을 발견해 설치 단계에 추가했다. 데스크톱·모바일 캡처를 직접 확인하고 모바일 제목 띄어쓰기·줄바꿈을 수정했다. 원격 CI·PR 병합 근거는 해당 PR에 별도 기록한다.

## 범위와 한계

실제 추출 화면이며 AI 추천·후보 선택·자막 편집·SNS 기능은 없다. localhost 개발용이고 인증·소유권·사용량 제한은 미구현이다. Chromium 데스크톱과 모바일 크기를 검사하며 실제 모바일 기기·Safari·Firefox 호환성은 별도 검증이 필요하다. 다운로드는 Blob으로 받아 브라우저 메모리를 사용한다. 장시간·대형 출력으로 확장할 때 스트리밍 다운로드와 오류 표시를 함께 설계한다.
