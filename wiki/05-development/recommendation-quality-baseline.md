# 추천 품질 기준선 측정 — VIDEO-005

> 추천 품질을 비교하려면 입력과 결과를 먼저 고정해야 합니다. 사람이 후보를 평가하는 기준선 측정 절차와 결과 보관·비교 조건을 안내합니다.

[위키 홈](../README.md) · [개발 목차](README.md)


## 목적과 현재 경계

선택·수정 이유 기록과 개선 회차 비교, 검사 기반 반복 실행은 [추천 개선 루프](recommendation-improvement-loop.md)를 따른다. 전용 화면보다 기존 도구로 수작업 1~3회를 먼저 수행한다.

VIDEO-004의 자동 검사는 처리 계약을 검증한다. VIDEO-005는 실제 한국어 대화·인터뷰에서 추천 후보가 쓸 만한지 사람이 평가한다. 현재 선택은 [Groq 무료 모드](groq-free-ai.md)이며 예산은 0원이다. 실제 실행에는 외부 전송이 허용된 영상, Groq Free 계정 확인, 로컬 키 설정이 필요하다. Azure·OpenAI 유료 경로는 이번 평가에서 활성화하지 않는다.

## 준비 순서

1. 사용 권한이 있는 한국어 영상 3개를 선정한다. 개발용 2개와 최종 확인용 1개를 미리 구분한다. 첫 연결은 그중 1개로 확인한다.
2. AI 결과를 보기 전에 사람이 추천할 만한 구간의 시작·종료 밀리초와 이유를 비공개 파일에 기록한다. 정답 구간이 유일하다고 가정하지 않는다.
3. 승인된 영상·제공자·예산을 기록하고 `.env`에 키를 설정한다. 키·영상·전사·사람 평가 원문은 Git/Wiki에 추가하지 않는다.
4. `uv run python -m scripts.evaluate_recommendations preflight`로 설정 유무만 확인한다. 이 명령은 인증 요청을 하지 않으며 키 값도 출력하지 않는다. 로컬 `.env`와 재생성 전 컨테이너 환경은 다를 수 있다.
5. 실제 실행 승인 후에만 AI를 활성화하고 분석 워커·API 설정을 반영한다. `/recommendations`에서 한 건만 접수한다. 기존 호출 제한은 달러 단위 예산 차단기가 아니므로 제공자별 단가·한도를 확인하지 않고 금액 준수를 보장하지 않는다.
6. 실패하면 오류 코드·provider_calls를 먼저 확인하고 자동으로 재접수하지 않는다. 외부 호출이 성공했지만 결과 저장이 실패한 경우에도 과금이 발생할 수 있다.

## 결과 고정과 사람 평가

분석 완료 후 아래 조회 전용 명령을 실행한다. POST나 유료 AI 호출은 하지 않는다. 새 디렉토리만 허용하며 기존 결과를 덮어쓰지 않는다.

```sh
uv run python -m scripts.evaluate_recommendations capture <analysis-id> --split development --output .artifacts/evaluations/dev-01
```

`snapshot.json`은 후보·모델 설정의 고정본이다. `review.json`에 평가자 식별명, 사전 기록한 references와 후보별 판단을 입력한다. 최종 확인용은 `--split holdout`으로 구분하고 그 결과를 보며 가중치를 조정하지 않는다.

| 항목 | 입력 기준 |
|---|---|
| usable | 실제 사용할 후보이면 true, 아니면 false. 미평가 null |
| boundaries | 0: 문장·의미가 잘림, 1: 큰 수정 필요, 2: 일부 수정 필요, 3: 작은 수정, 4: 그대로 사용 가능 |
| independence | 0: 이해 불가, 1: 앞뒤 맥락 필수, 2: 일부 설명 필요, 3: 대체로 이해 가능, 4: 독립적으로 이해 가능 |
| notes | 구체적인 실패 이유와 수정할 시간 구간 |
| transcription_notes | 의미를 바꾸는 오인식과 해당 시간. 정답 전사 없이 오류율을 임의 계산하지 않음 |
| diversity_notes | 같은 이야기 반복 여부와 추가로 필요한 주제 |

```sh
uv run python -m scripts.evaluate_recommendations report .artifacts/evaluations/dev-01
```

`report.json`은 사용 가능 비율, 경계·독립성 평균, 사전 구간과의 평균 최대 IoU(시간 교집합/합집합)를 기록한다. 미평가·평가자 없음·빈 후보는 incomplete이며 성공률을 0이나 100%로 채우지 않는다. 후보 ID 누락·중복·다른 분석 평가표는 거부한다. IoU는 참고 지표이며 사람의 선호 판단을 대체하지 않는다.

사용량과 시간은 PostgreSQL의 provider_calls, 분석 생성·종료 시각을 통해 별도로 확인한다. 제공자가 반환하지 않은 실제 비용은 null로 유지한다. 가격표를 적용한 추정액과 실제 청구액을 구분한다. 현재 도구는 자동 과금 집계나 비용 한도 강제를 구현하지 않는다.

## 비교와 완료 기준

첫 결과는 기준선이며 임의의 합격선을 통과했다고 표시하지 않는다. 동일 영상·원본 해시·모델·프롬프트 버전·사람 평가 기준을 고정해 이후 결과와 비교한다. 발견한 오류는 민감한 원문을 제거한 합성 회귀 사례로 바꾼다. 3개 표본은 초기 진단에 사용하며 여러 장르의 일반 성능을 입증하지 않는다.

완료 증거는 실제 분석 ID, 입력 식별자·해시, 설정 버전, 호출 기록, 사람 평가표, 기준선 보고서, 미해결 실패 목록이다. 지금은 평가 도구만 준비됐으며 실제 데이터의 증거가 없으므로 VIDEO-005 품질 평가 완료로 표시하지 않는다.
