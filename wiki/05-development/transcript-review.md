# 전사 자동 검수와 사람 판정

> 음성 인식의 신뢰도 정보는 오인식을 확정하는 정답이 아닙니다. 의심 구간과 앞뒤 음성을 사람이 확인하고 판정을 저장하는 사용 방법을 설명합니다.

## 사용과 한계

분석 결과에서 의심 구간의 앞뒤 2초를 재생하고 오류 있음·이상 없음·판단 어려움과 메모를 저장한다. 전체·미검수·비표시 표본 필터와 JSON 보고서를 제공한다. 판정은 원본 전사·SRT·추천 점수를 바꾸지 않는다. 로컬 단일 사용자 기능이며 외부 공개 전 인증이 필요하다.

`transcript-review-v1`의 초안 임계값은 avg_logprob < -1.0, no_speech_prob > 0.6(낮은 신뢰도와 동반), compression_ratio > 2.4다. 이전 구간과 공백 제거 문구가 같으면 반복 의심이다. 자막 길이·읽기 속도 등 표시 문제는 인식 문제와 구분한다. 단어 시각 없음 자체는 우선순위를 올리지 않는다. 신호를 구간별로 합치고 우선순위·시작 시간·ID로 정렬한다.

신호는 오류 확정이나 정확도 점수가 아니다. 실제 무음 판별·누락 발화 탐지·문맥 교정은 제공하지 않는다. 자연스러운 반복은 오탐할 수 있고 자연스러운 오인식은 놓칠 수 있다. 없는 신뢰도는 평가 불가로 남긴다. 검수 조회·재생·판정 저장은 추가 AI·FFmpeg·Celery 호출을 하지 않는다.

## 버전과 API

Groq v3는 기존 요청 응답의 선택 신뢰도 정보를 보존한다. v1·v2는 계속 읽되 자동 재전사·정보 복원을 하지 않는다. 명시적 새 분석은 v3 캐시를 사용하므로 전사 호출이 발생할 수 있다. 이전 버전에 고정된 대기 작업은 제공자 불일치로 거절하고 자동 재접수하지 않는다. 검수 메타데이터는 추천 프롬프트에서 제외한다.

- `GET /analyses/{id}/transcript-review`: 버전, 구간별 이유·관측값·평가 불가 지표·판정·revision·집계·비표시 표본 반환.
- `PUT /analyses/{id}/transcript-review/{segment_id}`: transcript_version, policy_version, revision, decision(error/ok/uncertain), note(최대 1000자). 미검수 revision은 0이며 동시 저장 충돌은 409다. 입력을 보존하고 새로 조회한 뒤 사용자가 다시 저장한다.
- `GET /analyses/{id}/review-audio`: 서버가 경로를 결정한 기존 MP3/WAV만 Range로 제공한다. 경로 이탈을 차단하고 파일 없음은 404로 표시하며 자동 변환하지 않는다.

완료 전은 409, 없는 분석·구간·음성은 404다. `0004_transcript_reviews`가 최신 판정 테이블을 추가한다. 분석·전사 버전·정책 버전·구간 ID로 분리하며 버전 간 판정을 승계하지 않는다. 전체 판정 이력은 저장하지 않는다.

## 평가와 검증

한국어 영상 3개를 개발 2·최종 확인 1로 고정해 의심 구간 중 실제 오류 비율, 비표시 표본에서 발견한 오류, 영상 1분당 검수 시간을 기록한다. 비표시 표본은 정책 버전 seed와 구간 ID의 결정적 해시 순서에서 최대 5개다. 표본만으로 전체 탐지율을 주장하지 않으며 정답 전사 없이 CER을 계산하지 않는다. 원본·검수 보고서는 공개 Git/Wiki에 올리지 않는다.

단위·통합 `test_transcript_review.py`에서 임계값·결측·원문 보존·버전·동시 저장·Range·Chromium 재생/판정/새로고침/보고서를 검사한다. 일반 CI는 합성 영상과 AI 대역만 사용한다. 실행 수치와 실제 품질 미평가는 현황 문서에서 구분한다.

로컬 실행 결과는 기본 251개·통합 57개 통과다. 기존 Starlette/httpx 사용 중단 예정 경고 1개는 남아 있다. 신뢰도 없는 기존 응답의 정규화 호환 실패를 발견해 선택 메타데이터가 없으면 기존 형식을 유지하도록 수정했고, Groq HTTP 대역에서 실제 메타데이터가 정규화까지 보존되는지도 검사했다. 새 DB 테이블은 격리 환경에서 실제 마이그레이션했으며 검수·재생 이후 제공자 호출 기록이 늘지 않는 것을 확인했다. 실제 영상 3개에 대한 사람 품질 평가는 미실행이고 커밋·푸시·Wiki 게시도 하지 않았다.
