# Shortform 개발자 안내

> 긴 영상에서 공유할 장면을 고르고, 원음을 들으며 자막을 고쳐 세로 영상으로 만드는 프로젝트입니다. 처음에는 10초 추출로 서비스를 실행해 보고, 같은 요청이 백엔드를 거치는 과정을 따라가세요.

1. **영상 하나를 잘라 보세요.** [로컬 실행](05-development/onboarding.md) 뒤 `/extract`에서 링크나 파일과 시작 시각을 입력합니다. 성공한 작업을 열어 10초 MP4를 내려받습니다. 후보를 찾는 제작실에서는 별도로 전사·추천을 활성화합니다. [후보부터 자막 편집까지](05-development/complete-flow.md)
2. **작업 번호를 따라가세요.** 브라우저가 접수 응답을 받으면 워커는 어디서 영상을 찾을까요? [요청 한 건의 처리 과정](03-architecture/system-overview.md#10초-추출-요청은-어디를-거치나)에서 DB에 남는 상태와 워커가 쓰는 파일을 확인하세요.
3. **출력 성공 뒤에 발견한 실패를 읽어 보세요.** 실제 영상은 끝까지 재생됐지만 원본 자막 아래에 같은 대사가 한 번 더 보였습니다. [969프레임과 SRT로 검증한 수정](05-development/harness/records/2026-11-18-final-output-e2e.md)에서 무엇을 비교했는지 볼 수 있습니다.
